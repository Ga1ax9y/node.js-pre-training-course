git init
git config user.name
git config user.email
git add .gitignore
git commit -m "Add .gitignore"
git add README.md package.json
git commit -m "Add README and package.json"
git log --oneline
output:
1cd92a5 (HEAD -> main) Add README and package.json
d14e756 Add .gitignore

- git init:
  Initializes a new empty Git repository in the current directory.

- git config user.name "Name":
  Sets the Git author name for this repository only.

- git config user.email "you@example.com":
  Sets the Git author email for this repository only.

- git add .gitignore:
  Stages the .gitignore file so it can be committed.

- git commit -m "Add .gitignore":
  Creates the first commit containing only the .gitignore file.

- git add README.md package.json:
  Stages both README.md and package.json together.

- git commit -m "Add README and package.json":
  Creates the second commit containing both README.md and package.json.

- git log --oneline:
  Shows the commit history in a compact format, with one line per commit.
